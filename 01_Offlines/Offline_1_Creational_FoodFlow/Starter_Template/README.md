# FoodFlow: Starter Template Skeleton

This directory contains the initial, unrefactored course distribution skeleton provided by the course instructors for **Offline 1 (FoodFlow)**.

---

## 🎯 Purpose

- Demonstrates the baseline ordering system before refactoring with the **Builder Pattern**.
- Includes the original `TestHarness.java`, CSV menu catalog (`data/menu.csv`), and assignment specification (`spec/assignment-spec.pdf`).
- Serves as the benchmark baseline against which student refactorings in [`Submission_2305025/`](../Submission_2305025/) are evaluated.
