# SmartHome: Reference Architectural Variant

This directory contains a clean, alternative reference solution for **Offline 2 (SmartHome)**.

---

## 🎯 Architecture

Implements the Composite Pattern (`SmartDevice`, `Room`, `Home`) and Decorator Pattern (`AccessRestricted`, `TimerControlled`, `PowerThrottled`, `EcoMode`, `GuestMode`) in a clean, self-contained single-file demonstration (`SmartHome.java`).

### 🚀 Compile & Run
```bash
javac SmartHome.java
java SmartHome
```
