# SmartHome: Initial Course Code Distribution

This directory contains the baseline starter code distributed by course instructors for **Offline 2 (SmartHome Automation Hub)**.

---

## 📁 Contents

- **`SmartHomeSpaghettiDemo.java`**: The baseline monolithic, unrefactored implementation demonstrating the anti-patterns of rigid inheritance, hardcoded device flags, and tight coupling prior to applying Composite and Decorator design patterns.
- **`SmartHomeTestRunner.java`**: Baseline test harness for verifying output assertions.

Refactored structural pattern solutions are maintained in [`../2305025/`](../2305025/).
