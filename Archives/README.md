# Course Project Archives Directory

This directory securely archives historical snapshots, initial assignment zip files, and student submission packages for **BUET CSE 214: Software Engineering & Object-Oriented Design Patterns Sessional**.

Each archive is categorized into a dedicated subfolder corresponding to its origin to avoid namespace collisions among similarly named submission zips (such as `2305025.zip`).
