### CSE 214 - Creational Pattern Online

**A2: Computer Model System**

You are designing a system to manage two computer models: WorkPro and LiteMax. They have differences in their Processor and Display. WorkPro is a professional computer that uses an Intel Xeon Processor and IPS display. LiteMax is more of a lightweight device that uses an ARM Processor and OLED display. There are two different companies, one of which only produces Processors and the other only produces Displays.

You have to implement the system where the user will select their preferred model. The system will create the computer with proper processor and display. The classes that represent the computers will contain functions to print the descriptions with model names, components, and other characteristics.

**Pattern:** Abstract Factory Pattern
